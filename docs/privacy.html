Privacy Policy

Last updated: 2026

AutoPoster Reiko ("the App") is a personal automation tool. This policy explains what data the App handles and how.

1. What data is accessed

The App accesses only the OAuth access/refresh tokens issued by each connected platform (such as TikTok) after the operator explicitly authorizes the connection. These tokens are used solely to publish video content to the operator's own account.

2. What data is NOT collected

The App does not collect, store, or process any personal data belonging to other users. It does not access followers, direct messages, analytics, or any data beyond what is required to publish a video (the video file itself and its caption/title).

3. Storage

Authentication tokens are stored as encrypted secrets in the App's private automation environment (GitHub Actions Secrets) and are never exposed in logs, code, or to any third party.

4. Data sharing

No data is sold, shared, or disclosed to third parties. The only data transmitted is the video content and caption sent directly to the target platform's official API for publishing.

5. Data retention

Tokens are retained only as long as needed to operate the App and can be revoked at any time by the operator directly from the connected platform's account settings.

6. Contact

For questions about this policy, contact the operator via the associated GitHub repository.
